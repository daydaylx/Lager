# Abnahmekriterien

## Schulbasis – End-to-End-Szenario

Profil:

```text
Fachkraft für Lagerlogistik
2. Ausbildungsjahr
```

Schultag:

```text
22.09.2026
Berufsschule

LF 8 · Güter verladen
- Ladungssicherung
- Stauplan

Wirtschaftskunde
- Tarifvertrag

Aufgabe:
Arbeitsblatt bis 25.09.2026
```

Nach Speichern muss gelten:

- SchoolEntry vorhanden,
- zwei SchoolBlocks vorhanden,
- Aufgabe vorhanden,
- Today zeigt Tag gespeichert,
- Week zeigt Berufsschultag,
- Berichtshefttext ist sinnvoll und enthält keine privaten Notizen,
- Lernfeldhistorie enthält LF 8,
- Schule-Home zeigt die Aufgabe,
- App-Neustart verliert keine Daten.

## Regression

- alter Lager-Tag bleibt lesbar,
- alter Verkäufer-Tag bleibt lesbar,
- Vorlagen funktionieren weiterhin,
- Wochenzusammenfassung funktioniert,
- OpenRouter-Berichtsfallback funktioniert,
- Export bestehender Daten bleibt möglich,
- `Alle Daten löschen` räumt neue und alte Daten auf.
