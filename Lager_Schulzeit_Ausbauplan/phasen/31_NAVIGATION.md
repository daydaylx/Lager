# Phase 31 – Navigation

## Ziel

Hauptnavigation auf täglichen Nutzen ausrichten.

## Vorher

```text
Heute | Woche | Vorlagen | Profil
```

## Nachher

```text
Heute | Woche | Schule | Profil
```

## Vorlagen

`Vorlagen` bleibt vollständig erhalten, wird aber über Profil/Einstellungen erreichbar:

```text
Profil
  Ausbildung
  Erinnerungen
  Darstellung
  Tätigkeiten
    Vorlagen verwalten
  Daten & Datenschutz
```

## Anforderungen

- kein fünfter Bottom-Navigation-Tab,
- bestehende Templates-Funktionalität nicht entfernen,
- Navigationstests aktualisieren,
- Android-App-Shortcut `Heute eintragen` unverändert.
