# Phase 37 – Schwächen-System

## Ziel

Lernbedarf aus echten Nutzerdaten ableiten.

## Quellen

- falsch beantwortete Karten,
- `Unsicher`,
- manuell markierte Themen,
- optional Ergebnisse aus Assessments,
- später Übungsmodus.

## Darstellung

Keine Gamification-Rangliste.

Beispiel:

```text
Noch unsicher
- Lagerkennzahlen: 8 offene Karten
- Ladungssicherung: 4
- Warenbeschaffung: 3
```

## Abnahme

Nutzer kann direkt aus einer Schwäche in eine passende Wiederholung starten.
